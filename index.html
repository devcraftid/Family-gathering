Buat Backup

Mengambil data langsung dari Supabase, lalu mengunduhnya sebagai file JSON.

Backup mencakup kursi_bus, absensi, event_settings, dan rundown_items.

Simpan file backup di lokasi aman. File dapat berisi nama dan nomor kontak peserta, jadi jangan dibagikan secara publik.

Pulihkan Backup

Memasukkan data dari file backup JSON kembali ke Supabase.

Pulihkan hanya dari backup milik website ini. Buat backup terbaru sebelum memulihkan data.

Pemulihan menggunakan upsert untuk peserta, pengaturan, dan rundown. Riwayat absensi akan ditambahkan jika belum dikenali; periksa hasilnya setelah proses selesai.

Catatan Keamanan

Fitur ini hanya tersedia setelah admin login. Backup tidak menyertakan password, token sesi, atau kunci rahasia Supabase. Jangan pernah menaruh service_role key di HTML atau file backup.
